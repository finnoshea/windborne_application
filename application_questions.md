2. Describe an ML idea you were initially excited about but later decided was wrong or unimportant. What changed your mind?

Using JEPA to make predictions on beam parameters at the LCLS linac. I was on board because embeddings seemed a perfect fit for making predictions along several kilometers of beam line. 

I rejected it because the literature was showing that it was failing after maybe 50 steps along the prediction chain. I used a strongly physics-based model of the beam line instead.  Inductive bias is powerful.

4. How could better accuracy fail to translate into more useful forecasts for a weather model?

Accuracy is a poor metric for performance if there is a lot of class imbalance.  To pick a silly example, a model that predicts 70-degrees and sunny in Los Angeles is probably going to be pretty accurate and also totally useless beacuse most Angelenos want to know when it is going to rain.  You have to understand your coverage along with accuracy, or use a different metric entirely.
